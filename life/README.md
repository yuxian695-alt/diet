# 纯过日子生活管家

给一个人过日子用的小工具：钱能存下来，冰箱别浪费，三餐好好吃，家里干干净净。

全部免费：不用服务器、不用 API、不用苹果开发者账号。数据只存在你的手机上。

## 六个页面

| 页面 | 能做什么 |
| --- | --- |
| 生活首页 | 本月还能花多少、冰箱里快过期的、今天吃什么、今日待办、采购清单、这个月的小成绩 |
| 生活账本 | 记支出 / 收入 / 存钱；韩元和人民币分开记，一键「全换成 ¥」或「全换成 ₩」看总数；按类别设每月预算，超了会变红；按月翻看明细 |
| 冰箱库存 | 记食材和到期日（常见食材自动填好能放几天）；按到期排序，3 天内到期会提醒；「−」用掉一份；吃完 / 扔掉会计入当月统计；推荐用现有食材能做的菜 |
| 一周三餐 | 从今天起 7 天的早午晚；点开看菜谱、食材和做法；「做好了」会从冰箱扣掉食材；也可以写「公司食堂」「外卖」 |
| 日常待办 | 今天 / 全部未完成 / 全部日期；可以设每天、每周重复，打勾后自动排到下一次；常做的小事一键加 |
| 采购清单 | 本周菜单缺的食材自动算出来；买到了打勾，「收进冰箱」一步入库，顺手把花的钱记进账本；复制清单发给自己 |

右上角：
- **搜索**：食材、菜名、待办、账目、清单一起搜
- **一键生成**：按冰箱里的食材、口味、做饭时间排一周三餐，快过期的先用掉，同一道菜不会连着吃，缺的加进采购清单
- **备份与恢复**：复制备份 / 下载备份文件，换手机时粘贴回来

## 自动记账（截图 / 小票 / 说一句）

- **截图 / 拍小票**：付款 App 截图（카카오페이、네이버페이、토스、微信、支付宝……）、超市小票、刷卡单都行，可以一次选好几张。认出金额、韩元还是人民币、类别、日期、付款方式，核对后再记。
  - 在 claude.ai 打开的版本：直接用 Claude 看图。
  - 装在桌面的版本（GitHub Pages）：不接 AI，所以免费。点「复制提示词」→ 在 Claude App 里粘贴并附上截图 → 把回复粘贴回来。
- **说一句**：现金或者懒得拍照时用，一行一笔，比如：
  ```
  现金 1.2万韩元 买菜
  地铁 1400；淘宝 58元 衣架
  昨天 便利店 3만2천원
  ```
  能认 `12000`、`12,000원`、`1.2万`、`3만2천원`、`¥58`、`58元`，还有「昨天」「11月20日」这样的日期。不写币种时，1000 以上算韩元，100 以下算人民币。
- **汇率**：账本里点「汇率」修改（默认 1 人民币 = 195 韩元，记得改成实际的）。桌面版可以联网查当天汇率（open.er-api.com）。汇率只影响换算出来的总数，每一笔原来的币种和金额不会变。

第一次打开是示例数据，点「清空示例，开始记我的」就从零开始。

## 装到 iPhone 桌面
1. 用 **Safari** 打开上面的网址
2. 点底部 **分享** → **添加到主屏幕** → **添加**。如果看到「作为 Web App 打开」的开关，把它**关掉**
3. 之后点桌面图标，会在 Safari 里打开。这样和「敲两下记账」的快捷指令用的是同一份数据（iPhone 上独立的 Web App 和 Safari 数据不互通）

## 敲两下手机背面，自动记账（快捷指令）

付完款停在「支付成功」页面或小票上，敲两下手机背面：自动截图 → 手机自带的文字识别认出上面的字 → 打开生活管家，自动记一笔。文字识别在手机上完成，不花钱。

**做快捷指令（只做一次）**：打开「快捷指令」App → 右上角 **+** → 依次添加这 4 个操作：
1. **截取屏幕快照**
2. **从图像中提取文本**
3. **URL 编码**
4. **打开 URL**：输入框里先粘贴 `https://yuxian695-alt.github.io/diet/life/#shot=`，紧跟着插入变量「URL 编码后的文本」

起名「记一笔」，点完成。然后 **设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下**，选「记一笔」。第一次运行时允许它打开网址。

App 里「生活账本 → 设置：敲两下手机背面」有同样的步骤和一键复制的网址。

- 认准了会直接记好，屏幕下方出现「撤销」；没认准、或者看起来记过了，会先让你核对。
- 付款完成页、带「합계 / 결제금액 / 实付」的小票最准。卡片短信、카카오페이、토스、微信支付成功页都能认。

## 数据和备份
- 数据存在手机 Safari 里，不会上传到任何地方。
- 换手机、清理 Safari 之前，先在「备份与恢复」里复制一份备份存到备忘录。

## 以后要改功能
改好 `index.html` 重新上传覆盖即可。如果手机上还是旧版本，从桌面打开后关掉再开一次；改了 `sw.js` 里的 `CACHE` 名字会强制更新缓存。
